# 個人IP運營中控台

給經營個人品牌的人用的運營後台：拍完的影片丟進來，一路走到發布，文案、檔期、字幕都有 AI 幫忙。
**下載就能用**：不用安裝、不用架伺服器、不用註冊帳號。

## 三種用法，選一種

| 用法 | 適合 | 怎麼做 |
| --- | --- | --- |
| A. 下載直接開 | 只在一台電腦用 | 下載 ZIP → 解壓縮 → 用 Chrome 或 Edge 打開 `index.html` |
| B. GitHub Pages 免費網址 | 想用手機、想有固定網址 | 把專案放到自己的 GitHub → Settings → Pages → 選 `main` 分支 → 得到一個網址 |
| C. 雲端版（`cloud/` 資料夾） | 多台裝置同步、要密碼登入、影片存雲端 | 部署到自己的 Cloudflare 帳號，見 `cloud/README.md` |

A 和 B 的資料都存在「打開它的那個瀏覽器」裡，只有你看得到。換電腦或換瀏覽器時，用「設定 → 備份與搬家」帶走資料。

## 功能

| 功能 | 說明 |
| --- | --- |
| 首頁儀表板 | 待剪輯、待審核、已排程數量，內容流水線，最近動態，下一場活動，新手四步驟 |
| 內容看板 | 每支影片一張卡：狀態、類別、預計發布時間、要發的平台、文案 |
| 上傳影片 | 影片存在瀏覽器裡（1 GB 以內），也可以只貼雲端硬碟連結 |
| AI 文案工作室 | 一支影片發全部平台、短影音標題、社群貼文、群組通知、招生文案、難回訊息的高情商回覆、主持串場稿、本週內容包 |
| 免金鑰模式 | 沒有 AI 金鑰也能用：按「複製提示詞」，貼到自己的 ChatGPT 或 Claude |
| 自動字幕 | 把影片的話轉成 SRT 字幕檔，可匯入 CapCut 或上傳 YouTube（需 OpenAI 相容的語音服務，影片 25 MB 以內） |
| 發布包 | 下載影片、複製文案、一鍵開啟 TikTok Studio、YouTube Studio、Meta 商務套件 |
| 活動檔期 | 貼上跟客戶的對話，AI 整理成檔期、流程與確認訊息；每場活動六步檢查 |
| 範本庫 | 招生、花絮、成果分享、預告、節日問候、活動確認、前一天提醒、活動後感謝、婉拒撞期 |
| 設定 | 品牌名稱與顏色、介紹、受眾、語氣、禁用字、平台、AI 服務與金鑰、備份與匯入 |

手機、平板、電腦都能用。品牌顏色一換，整個網站跟著變色。

## 第一次使用

1. 打開網站，到「設定」填品牌名稱、介紹、語氣，選自己經營的平台和品牌顏色。
2. （可略過）選 AI 服務並貼上金鑰：
   - Claude（Anthropic）：模型例如 `claude-sonnet-5-5`。
   - OpenAI 相容服務：填服務網址與模型名稱；要用自動字幕請選這個。
3. 上傳第一支影片。

## 每天怎麼用

1. 拍完 → 上傳影片，寫一句想怎麼剪。
2. 剪好 → 在卡片產生字幕、用 AI 寫各平台文案。
3. 自己看過 → 狀態改「已排程」。
4. 打開「發布包」：下載影片、複製文案、到各平台設定發布時間。
5. 發出去後狀態改「已發布」。

## 安全與限制

- AI 金鑰只存在你這台裝置的瀏覽器裡，AI 請求直接從瀏覽器送到 AI 服務。**不要在公用電腦存金鑰。**
- 清除瀏覽器資料會一起清掉這個網站的資料，請定期「下載備份檔」。備份不含金鑰與影片檔。
- 發布是半自動：網站準備好影片、文案與平台入口，最後由人到各平台按發布。
- AI 只寫稿，發出去之前一定要有人看過。
- 翻唱或使用別人的音樂，可能被平台版權系統偵測。
