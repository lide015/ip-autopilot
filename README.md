# 個人IP運營中控台

給經營個人品牌的人用的運營後台：拍完的影片丟進來，一路走到發布，文案、檔期、字幕都有 AI 幫忙。
每位使用者部署自己的一份，資料只存在自己的 Cloudflare 帳號裡，只有自己能登入。

## 功能

| 功能 | 說明 |
| --- | --- |
| 首頁儀表板 | 待剪輯、待審核、已排程數量，內容流水線，最近動態，下一場活動 |
| 內容看板 | 每支影片一張卡：狀態、類別、預計發布時間、要發的平台、文案 |
| 上傳影片 | 100 MB 以下直接上傳（有進度條），更大的檔案貼雲端連結 |
| AI 文案工作室 | 一支影片發全部平台、短影音標題、社群貼文、群組通知、招生文案、難回訊息的高情商回覆、主持串場稿、本週內容包 |
| 免金鑰模式 | 沒有 AI 金鑰也能用：按「複製提示詞」，貼到自己的 ChatGPT 或 Claude |
| 自動字幕 | 把影片的話轉成 SRT 字幕檔（需 OpenAI 相容的語音服務，影片 25 MB 以內） |
| 發布包 | 下載影片、複製文案、一鍵開啟 TikTok Studio、YouTube Studio、Meta 商務套件 |
| 活動檔期 | 貼上跟客戶的對話，AI 整理成檔期、流程與確認訊息；每場活動六步檢查 |
| 範本庫 | 招生、花絮、成果分享、預告、節日問候、活動確認、婉拒撞期等範本 |
| 設定 | 品牌名稱與顏色、介紹、受眾、語氣、禁用字、平台、AI 服務與金鑰、改密碼、下載備份 |

手機、平板、電腦都能用。

## 部署（不用在自己電腦裝任何東西）

需要一個 Cloudflare 帳號（免費方案即可開始）。

### 方法一：一鍵部署（倉庫需為公開）

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/lide015/ip-autopilot)

按下按鈕、登入 Cloudflare、確認名稱，Cloudflare 會自動建立資料庫與影片儲存空間並上線。

### 方法二：從自己的 GitHub 匯入（私人倉庫也可以）

1. 取得這個專案的一份副本到自己的 GitHub（例如由賣家邀請或用範本建立）。
2. 登入 Cloudflare 後台 → Workers 與 Pages → 建立 → 匯入存放庫，選這個倉庫。
3. 建置指令留空，部署指令用 `npx wrangler deploy`，按部署。
4. 資料庫（D1）與影片儲存（R2）會在第一次部署時自動建立，資料表在第一次開網站時自動建立。

## 第一次使用

1. 打開部署好的網址，設定一組登入密碼（至少 8 個字）。
2. 到「設定」填品牌名稱、介紹、語氣，選自己經營的平台和品牌顏色。
3. （可略過）到「設定」選 AI 服務並貼上金鑰：
   - Claude（Anthropic）：模型例如 `claude-sonnet-5-5`。
   - OpenAI 相容服務：填服務網址與模型名稱；要用自動字幕請選這個。
   - 金鑰只存在自己的資料庫、只在伺服器端使用，不會傳回瀏覽器。
4. 上傳第一支影片，開始使用。

## 每天怎麼用

1. 拍完 → 上傳影片，寫一句想怎麼剪。
2. 剪好 → 在卡片產生字幕、用 AI 寫各平台文案。
3. 自己看過 → 狀態改「已排程」。
4. 打開「發布包」：下載影片、複製文案、到各平台設定發布時間。
5. 發出去後狀態改「已發布」。

## 限制與注意

- 發布是半自動：網站準備好影片、文案與平台入口，最後由人到各平台按發布。
- 上傳上限 100 MB（Cloudflare 單次請求上限），更大的檔案請壓縮或貼雲端連結。
- 自動字幕需要 OpenAI 相容的語音轉文字服務，影片 25 MB 以內。
- AI 只寫稿，發出去之前一定要有人看過。
- 翻唱或使用別人的音樂，可能被平台版權系統偵測。

## 技術架構

- Cloudflare Workers（網站與 API）、D1（資料）、R2（影片），全部在一個 Cloudflare 帳號內。
- 前端：`public/`（HTML、CSS、JavaScript，無需建置）。
- 後端：`src/index.ts`。
- 登入：PBKDF2 雜湊密碼、HttpOnly 工作階段 Cookie、連續錯誤 5 次鎖 10 分鐘。

開發者本機測試：`npm install`、`npm run dev`。
