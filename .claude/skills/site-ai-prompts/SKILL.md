# AI 任務與提示詞

## 三個地方要一致
1. `app.js` 的 `TASKS`：畫面上的任務按鈕（`[代號, 名稱, 輸入提示]`）。
2. `store.js` 的 `TASKS`：本機版提示詞（`代號: [名稱, 要求]`）。
3. `cloud/src/index.ts` 的 `TASKS`：雲端版提示詞（`代號: { name, guide }`）。
代號、名稱、要求三處完全相同。改完跑 `npm test` 與雲端型別檢查。

## 輸出格式合約（不要改）
- 一般任務：AI 只回 `{"items":[{"label":"項目名稱","text":"可直接複製的完整內容"}]}`。畫面依 `items` 一張張顯示並可複製。
- 活動整理（`event`）：固定欄位 `name type date time place contact role flow[] needs[] open[] confirm`。
- 要新的輸出格式時，新增任務代號與對應的畫面處理，不要改動既有格式。

## 寫「要求」的守則
- 寫清楚**數量、字數、結構**（例如「輸出 3 個版本，各 150 字內，結尾一個行動呼籲」）。
- 品牌語氣不要寫在任務裡，由 `systemPrompt()` 依使用者設定統一帶入。
- 必須保留的安全規則（在 `systemPrompt`）：不編造事實、缺資料用【待填：項目】、公開貼文不放價格與客戶個資、繁中台灣用語。
- 提示詞不要提到任何真實人物或品牌。

## 驗證
- 沒有金鑰也要能用：「複製提示詞」產生的文字要完整（system＋任務），貼到任何 AI 都能用。
- 有金鑰時，用一個真實例子跑一次，確認回傳能被 `parseJson` 解析、畫面正常顯示。
